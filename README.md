# Kamus Tunjung

Proyek dokumentasi dan pelestarian bahasa Tonyooi (Tunjung) — kamus dua arah dan panduan singkat penggunaan.

Tujuan
- Mendokumentasikan kosakata Tonyooi → Indonesia dan Indonesia → Tonyooi.
- Menyediakan format data (CSV, JSON) untuk keperluan penelitian, aplikasi kamus, dan distribusi.

Isi repositori
- `tonyoooi_to_indonesia.csv` — Daftar pasangan Tonyooi → Indonesia (CSV).
- `tonyoooi_to_indonesia.json` — (akan ditambahkan) Versi JSON dari CSV.

Panduan singkat
1. Untuk melihat daftar kata cepat, buka `tonyoooi_to_indonesia.csv`.
2. Untuk penggunaan programatik, gunakan file JSON (akan ditambahkan).
3. Jika ingin menambahkan entri baru, ajukan pull request atau buka issue dengan format: `Tonyooi,Indonesia,Catatan`.

Kontribusi
- Kontribusi dari penutur asli, ahli bahasa, dan relawan sangat diharapkan.
- Silakan buka issue untuk koreksi ejaan, pelafalan, atau penambahan istilah baru.

Lisensi
